2. Connect the power adapter to charge the battery
3. Press the power button to start initial setup
4. Follow the on-screen setup wizard
5. Create your user account and password
6. Connect to Wi-Fi network
7. Install any pending system updates

FEATURES AND USAGE
The Laptop Pro comes with several advanced features:

Performance Mode: Press Fn+F5 to toggle between power saving and performance modes. Performance mode increases CPU and GPU performance for demanding tasks.

Cooling System: The laptop features an advanced cooling system with dual fans and heat pipes. The system automatically adjusts fan speed based on temperature.

Connectivity: Multiple ports including USB-C, USB-A, HDMI, and audio jack. The USB-C ports support charging, data transfer, and display output.

Security: Built-in fingerprint reader and TPM 2.0 chip for enhanced security. Windows Hello facial recognition is also supported.

TROUBLESHOOTING
Common issues and solutions:

Laptop won't turn on:
- Check if battery is charged
- Try holding power button for 10 seconds
- Connect power adapter and try again

Slow performance:
- Check for background applications
- Run disk cleanup utility
- Ensure adequate ventilation
- Update device drivers

Wi-Fi connectivity issues:
- Restart network adapter in Device Manager
- Forget and reconnect to network
- Update Wi-Fi drivers
- Check router settings

MAINTENANCE
Regular maintenance ensures optimal performance:
- Clean screen with microfiber cloth
- Use compressed air to clean vents monthly
- Keep software updated
- Run antivirus scans regularly
- Backup important data
